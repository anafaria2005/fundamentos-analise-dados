# 📊 Fundamentos de Análise de Dados

## 🎯 Objetivo
Este projeto tem como objetivo estudar os conceitos básicos de análise de dados.

## 📚 Fontes
- https://www.ibm.com/topics/data-analysis
- https://www.kaggle.com/learn
- https://learn.microsoft.com/pt-br/training/modules/data-analytics-microsoft
- https://pandas.pydata.org/docs
- https://www.coursera.org/articles/data-analytics

## 🤖 Prompts utilizados
- Explique análise de dados de forma simples
- Quais são as etapas da análise de dados?

## 📘 Resumo
A análise de dados envolve coleta, limpeza, análise e visualização de dados.

## 📌 Glossário
- ETL: Extract, Transform, Load
- EDA: Análise exploratória de dados
